# ORBITECH-TV WORLD — USER END

User-facing ORBITECH-TV WORLD IPTV package.

## Included
- ORBIT Channel Director and live player
- World channel catalogue
- Country, category, language and quality filters
- Search and favorites
- 5-minute demo access and channel packages
- User profile/access portal
- Responsive desktop/mobile interface
- ORBIT branding and player watermark

## User access
Open `index.html` for the main ORBIT TV experience or `user.html` for the user portal.


## Important
This package contains no Super Admin interface or admin JavaScript. Existing user-facing functionality remains unchanged.
